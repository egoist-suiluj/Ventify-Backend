# Ventify-Backend
The core backend service for Ventify, an emotional support application. This repository handles user data, message processing, and API endpoints for non-judgmental venting.

✨ Ventify Backend: The Core Emotional Support Engine
Ang Ventify ay isang non-judgmental emotional support application. Ang backend na ito, na binuo gamit ang Python, ang nagbibigay-lakas sa aming pangakong makinig at magbigay ng ligtas na espasyo para maglabas ng sama ng loob ang mga user, nang walang unsolicited advice.
